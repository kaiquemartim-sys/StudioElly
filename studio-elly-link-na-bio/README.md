# Studio Elly – Link na Bio

Mini site (link na bio) do Studio Elly Nails – Surubim-PE.

## Estrutura
- `index.html` – página
- `style.css` – estilos
- `script.js` – links dos botões (edite o WhatsApp e o Maps aqui)
- `images/` – fotos

## Publicar no GitHub Pages
1. Envie todos os arquivos para a raiz do repositório
2. Settings > Pages > Branch `main` / pasta `/ (root)` > Save
